How it works

  1. Analyze text

    Estimate emotion labels, valence, and arousal from your description.

  2. Build a prompt

    Combine the text and selected style with color and lighting cues.

  3. Generate an image

    Render with the configured backend. Download the image or try another seed.

About NovaVision

NovaVision is a prototype for image prompts guided by text emotion labels. It supports local diffusion models, hosted image generation, and synthetic test images.
