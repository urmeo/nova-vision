Text to image

Four steps from your description to a generated image

  1. Text

    A feeling, memory, or scene.
    Choose a visual style.

  2. Text analysis

    Seven emotion labels.
    Word scores + label presets → valence and arousal.

  3. Prompt

    Your text + visual style.
    Emotion cues add mood, palette, and lighting.

  4. Image

    Render with the selected backend.
    Download the image or report.

Neutral text skips emotion cues. Text scores are model estimates; they have not been validated against human feelings. Image analysis runs separately in the research experiments.

About NovaVision

NovaVision is a prototype for image prompts guided by text emotion labels. It supports local diffusion models, hosted image generation, and synthetic test images.
